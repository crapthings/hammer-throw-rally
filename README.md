# Hammer Throw Rally · 撇铅球大会

A browser arcade game set at a riverside school sports festival. Charge up, hurl a chained hammer down a 1,200 m course, and try to land it in the final hole. Collect coins, dodge pits and airborne obstacles, and grab rockets for a boost. At 150% power or higher, you might go flying with the hammer.

**[Play on GitHub Pages](https://crapthings.github.io/hammer-throw-rally/)**

Move the mouse up or down to aim. Hold the left mouse button to charge and release it to throw. Press Space to skip the plane rescue slow motion. Settings lets you switch between English and 简体中文 and adjust audio levels.

## Run locally

Requires Node.js 24 and pnpm 12.

```sh
pnpm install
pnpm dev
```

Use `pnpm build` to create a production build. The game uses React, PixiJS, Rapier, and Zustand.
